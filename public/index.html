// Étapes

Comment ça marche

Quatre étapes, sans quitter cette page.

01
Génère ton code — entre ton numéro (ou choisis le QR) puis lance la génération.
02
Ouvre WhatsApp — Réglages ⋮ → Appareils liés → Lier un appareil.
03
Lie ton compte — « Lier avec un numéro de téléphone » puis entre le code, ou scanne le QR.
04
C'est prêt — tape menu dans une conversation pour voir toutes les commandes.
